Google Workspace directory export with GAM, 2026-09-28

Run on the admin workstation with GAM 7.48.14, authorized as the tenant's super admin through
the admin OAuth client only (no service-account key, no domain-wide delegation). Each block is
the command as typed, followed by GAM's CSV output. gam.cfg sets the default domain and a local
timezone, so addresses are complete and times are omitted, leaving dates. Fields were chosen so that nothing
here grants access or identifies a person outside the lab: no object IDs, no recovery contacts,
no customer ID.
